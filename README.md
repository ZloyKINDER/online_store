# Проект "Интернет магазин"

## Описание:
Проект созданный в учебных целях Django

## Приложения:
1. catalog - Каталог товаров
2. blog - Статьи и новости


## Шаблоны catalog:
1. base.html - Базовый шаблон
2. footer.html - Шаблона подвала
3. header.html - Шаблон шапки
4. product_create.html - Шаблон для создания
5. product_detail.html - Шаблон для подробной информации
5. product_list.html - Шаблон для отображением

## Шаблоны blog:
1. base.html - Базовый шаблон
2. footer.html - Шаблона подвала
3. header.html - Шаблон шапки
4. blog_create.html - Шаблон для создания и редактирования
5. blog_detail.html - Шаблон для подробной информации
6. blog_list.html - Шаблон для отображением
7. blog_confirm_delete.html - Шаблон для подтверждения удаления
